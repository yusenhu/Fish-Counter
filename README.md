# Fish Counter System

## Overview
This project develops a non-invasive system to count endangered fish as they are transferred through a 4-inch hose using a fish-friendly pump at UC Davis.

## Motivation
Manual counting causes stress to fish and is not scalable. This system provides an automated, real-time solution using optical sensing and computer vision.

## System Architecture
- Inline optical sensing module
- Embedded processing unit
- Computer vision-based fish detection and tracking
- Data logging and validation

## Repository Structure
- `hardware/` – CAD models, schematics, and mounting designs
- `software/` – Data collection and image processing algorithms
- `tests/` – Validation and accuracy testing scripts
- `results/` – Plots and experimental data
- `docs/` – Technical documentation and reports
